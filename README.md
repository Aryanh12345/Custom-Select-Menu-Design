# 🎨 Custom Select Menu Design

A modern and interactive **Custom Select Menu** built using **HTML, CSS, and JavaScript**.

This project demonstrates how to create a customized dropdown/select menu with a clean user interface and interactive JavaScript functionality.

## 🌐 Live Demo

👉 **[Visit Custom Select Menu](https://aryanh12345.github.io/Custom-Select-Menu-Design/)**

## 🚀 Features

- 🔽 Custom dropdown/select menu
- 🖱️ Interactive menu options
- ✨ Smooth animations and transitions
- 🎨 Clean and modern design
- 📱 Responsive layout
- ⚡ Lightweight and fast
- 💻 Built using pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, layout, animations, and transitions
- **JavaScript** – Dropdown interaction and menu functionality
